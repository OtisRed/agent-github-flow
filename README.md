# Agent GitHub Flow

Wspólny proces pracy agentowej i automatyzacja GitHub dla projektów. Pierwsza rzeczywista próba kontrolera obejmuje jeden wybrany projekt; podłączenie VSone oraz tego repozytorium wymaga osobnego kontrolowanego przełączenia.

Repozytorium jest na etapie **bootstrapu**. Kontroler MVP uruchomiono na Mikrusie dla jednego projektu: rzeczywiste przekazanie, zapis checkpointu i odzyskanie po restarcie sprawdzono na jednej karcie. Jednorazowa kopia bazy znajduje się poza serwerem; automatyzacja kopii, nocne uzgadnianie w wyznaczonym czasie, odzyskiwanie po utracie serwera i kolejne projekty nadal wymagają weryfikacji.
